# СменаБел v2 — сообщения на каждую фазу

Для владельца. Копируй блок целиком и отправляй. Квадратные скобки заменяй своим текстом.
ТЗ: `design/REDESIGN_V2_BRIEF.md`. Скриншоты отклонённого дизайна: `design/reference/rejected-ledger/`.

## Как давать обратную связь после каждой фазы

```
Фаза [N] — решение: принято / принято с правками / переделать
Нравится: [что оставить как есть]
Не нравится: [что убрать и почему — хватит одного слова «почему»]
Изменить:
1. [экран — что именно]
2. [...]
Взять из другого направления: [если есть]
```

Смотри на телефоне, а не на мониторе: открой страницу дизайнера на iPhone или пришли себе скриншоты. Приложение живёт в руке.
