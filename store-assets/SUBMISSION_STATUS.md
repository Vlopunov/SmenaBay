## Главный нерешённый вопрос: бэкенда нет

`USE_FIRESTORE = false` в `src/services/firestore.js`. Всё живёт в Zustand +
AsyncStorage **на устройстве**. Практические следствия:

- заказчик публикует смену → исполнитель на другом телефоне её не увидит;
- отклик не доходит до заказчика;
- сообщение в чате не доставляется — собеседник его не получит;
- регистрация не создаёт аккаунт нигде, кроме памяти телефона;
- переустановка приложения стирает всё.

То есть при первом же открытии двух устройств видно, что это витрина, а не
работающий сервис. Это Guideline 2.1 (App Completeness) и 4.2 (Minimum
Functionality) — **самый вероятный повод для отказа из оставшихся**.

### Почему Firestore выключен

Коммит `b155cad` убрал `@react-native-firebase/firestore`: он не собирался
под iOS с `useFrameworks: "static"` без дополнительной настройки подов gRPC.
Решение было правильным для сборки, но оставило приложение без данных.

### Рекомендуемый путь — Firestore через JS SDK

`firebase` (JS SDK v12) **уже в зависимостях** и сейчас не используется.
Его Firestore работает в React Native и не тянет нативные поды, то есть
обходит ровно ту проблему, из-за которой нативный модуль убрали:

```js
// src/services/firebase.js
import { initializeFirestore } from 'firebase/firestore';
export const db = initializeFirestore(app, {
  experimentalForceLongPolling: true,   // RN не умеет gRPC-стримы
});
```

Phone Auth остаётся на `@react-native-firebase/auth` — нативный SDK нужен
для тихой верификации через APNs.

Объём работы:

1. Переписать `src/services/firestore.js` с namespaced-API на модульный
   (`collection`, `doc`, `getDocs`, `onSnapshot`) — ~280 строк, структура
   коллекций уже спроектирована.
2. Написать Firestore Security Rules — сейчас их нет вообще. Без них база
   открыта всему интернету.
3. Привязать `currentUser.id` к Firebase Auth UID вместо `'w_' + Date.now()`.
4. Залить стартовые данные (`scripts/seed.mjs` уже есть).
5. Включить `USE_FIRESTORE = true` и включить обратно realtime-подписки в
   `firestoreSync.js`.

Пока это не сделано, приложение имеет смысл заливать в **TestFlight** для
внутреннего теста, но не отправлять на публичное ревью.

## Технический долг (не блокирует)

- Все 8 весов Unbounded и полный набор шрифтов `@expo/vector-icons` попадают
  в бандл — примерно 7 MB лишнего. Лечится импортом из подпутей.
- Локальная машина на Intel: RN 0.81 распаковывает `React.xcframework` без
  симуляторного слайса, из-за чего `Copy XCFrameworks` падает. Обход —
  скопировать полную версию из `ios/Pods/React-Core-prebuilt/<hash>/`.
  На EAS (Apple Silicon) проблемы нет.
- `src/screens/worker/WorkerProfileScreen.js`: пункт меню «Документы» ведёт
  на экран личных данных, где раздела документов нет.
