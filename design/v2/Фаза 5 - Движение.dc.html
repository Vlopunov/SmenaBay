ТАБЛИЦА ДЛЯ К4 · АНИМАЦИЯ → ТОКЕН → REANIMATED → HAPTIC → REDUCE MOTION

Пружины заданы через withSpring с параметрами damping / stiffness / mass; тайминги — через withTiming с Easing.bezier(.23,1,.32,1). Анимируются только transform и opacity — никаких width, height и цвета на UI-потоке; в прототипе height и background использованы для наглядности, в коде их заменяют scale и наложенные слои. Haptics — expo-haptics.
