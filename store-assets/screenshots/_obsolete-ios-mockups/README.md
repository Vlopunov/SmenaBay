# НЕ ЗАГРУЖАТЬ В APP STORE

Эти изображения **не являются скриншотами приложения**. Они нарисованы
скриптом `store-assets/make_screenshots.py` (PIL) в старом фиолетовом
дизайне, а `make_ios_screenshots.py` просто отмасштабировал их под
размеры iPhone и iPad.

Приложение с апреля 2026 выглядит иначе — «Editorial Workforce»:
бумажный фон `#F4F1EA`, сигнальный жёлтый, шрифт Unbounded. В этих
макетах ещё и текст обрезан по краям.

Загрузка их в App Store Connect — нарушение Guideline 2.3.3
(скриншоты должны показывать приложение в работе).

**Настоящие скриншоты:** `store-assets/screenshots/ios-iphone69/` —
сняты с Release-сборки в симуляторе iPhone 16 Pro Max, 1320×2868.

Папки `phone/`, `tablet7/`, `tablet10/` оставлены как есть — они
использовались для Google Play.
