# 📸 Как сделать скриншоты для Google Play

**Требования Google Play:**
- Минимум **2 скриншота** (рекомендую 4–8)
- Формат: PNG или JPEG
- Размер: 16:9 или 9:16 (вертикальные лучше конвертят)
- Минимум 320 px по короткой стороне, максимум 3840 px
- Рекомендуемый: **1080×1920** или **1440×2560**

---

## Вариант A — сделать на реальном Android телефоне (самый быстрый)

1. Установи APK на свой телефон. Собери APK-билд (для установки вручную):
   ```bash
   cd /Users/vladlopunov/Downloads/ServiceHub
   eas build --platform android --profile preview --non-interactive
   ```
   (профиль `preview` даёт APK вместо AAB)

2. Скачай APK из EAS → перекинь на телефон → установи.

3. Пройди по ключевым экранам, делая скриншот каждого (Power + Volume Down):
   - Главный экран со списком смен
   - Карточка смены (детали)
   - Карта со сменами рядом
   - Чат
   - Профиль
   - Форма создания смены (со стороны работодателя)

4. Перекинь на Mac через AirDrop / облако → загрузи в Play Console.

---

## Вариант B — Android Studio Emulator

1. Установи Android Studio, запусти эмулятор Pixel 6 API 34.
2. Поставь APK: перетащи `.apk` в окно эмулятора.
3. Скриншот: кнопка камеры на панели эмулятора (вертикально на экране правого тулбара), файл сохраняется в `~/Desktop`.

---

## Вариант C — готовые «красивые» скриншоты через device frame

В Play Console можно загружать скрины прямо из эмулятора, но для маркетингового вида — оберни их в рамку устройства:

- https://mockuphone.com — бесплатно, есть Pixel, Galaxy.
- https://screenshots.pro — платно, но с текстовыми подписями.
- Figma шаблоны «Google Play Store Screenshots».

---

## Что показывать на скриншотах (сильный порядок)

1. **Карточка вакансии** (hero-screen) — красивая смена с фото, адресом, оплатой.
2. **Список смен** с фильтрами.
3. **Карта** со сменами рядом.
4. **Чат** с работодателем.
5. **Профиль** с рейтингом и отзывами.
6. **Создание смены** (взгляд работодателя) — показывает двустороннесть платформы.

Добавь поверх каждого скриншота **короткий заголовок** (шрифт крупный, 2–4 слова):
- «Смены рядом с тобой»
- «Заявка в один тап»
- «Карта вакансий»
- «Чат с работодателем»
- «Рейтинг и отзывы»
- «Публикуй смены за минуту»

## Быстрый совет

Если поджимают сроки — сделай даже 2 скриншота без рамок и заголовков, загрузи, получи одобрение, потом заменишь на красивые. Google разрешает обновлять store listing без нового билда.
