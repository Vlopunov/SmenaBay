## Бэкенд подключён (18 сентября 2026)

Приложение больше не работает на моках. Все данные идут через API сайта
`smenabel.by/api` (Next.js на Vercel, Firestore через Admin SDK, проект
`smenabay` — тот же, что и у веба). Причина такой схемы: у многих
белорусских провайдеров `firestore.googleapis.com` недоступен, поэтому
клиентский SDK молча не работает. Firebase Auth живёт на другом хосте и
работает, так что телефон авторизуется сам и шлёт ID-токен на наш сервер.

- `src/services/api.js` — транспорт: токен, таймауты, офлайн, повтор при
  протухшем токене, русские сообщения на коды ошибок сервера.
- `src/services/backend.js` — по функции на каждое действие стора.
- `src/services/sync.js` — `/api/data/bootstrap` при запуске, при возврате
  в приложение и каждые 30 секунд; гость опрашивает публичную ленту.
- Стор остался мгновенным: сначалалокальное изменение, потом сервер, при
  отказе — откат и тост. Сервер решает там, где обязан: отклик, место на
  смене, создание чата.
- `id` пользователя = Firebase uid, поэтому аккаунт один на всех устройствах.

### Сделано в панелях (18 сентября)

- Vercel → Environment Variables: добавлен `CRON_SECRET` (Production), продакшен передеплоен.
- GitHub → Secrets: тот же `CRON_SECRET`. Проверено: ручной запуск workflow «Shift reminders» вернул `{"ok":true,"shifts":0,"reminded":0}`.
- Firebase → Authentication → Phone → номера для тестирования:
  `+375 29 000-00-01` → `111111`, `+375 29 000-00-02` → `222222`.
  Эти пары идут в App Store Connect для ревьюера.
- Проверка сквозная: смена, опубликованная на сайте, появилась в
  `/api/public/shifts` — том самом эндпоинте, который читает лента гостя.

### Осталось решить (стоит денег)

| Что | Зачем | Цена |
|---|---|---|
| Firebase Blaze | **Лимит 10 SMS в сутки** на бесплатном тарифе — это потолок регистраций. Плюс Cloud Storage: без него не грузятся фото профиля и фото в чате (`/api/upload` отвечает 503) | оплата по факту, при текущих объёмах — центы |
| Vercel Pro | Автоматическая защита Vercel иногда отдаёт HTML-челлендж вместо ответа API. Браузер его проходит, приложение — нет. Правило-исключение для `/api/*` доступно только на Pro | $20 в месяц |

Приложение на челлендж реагирует честно: «Сервер сейчас не отвечает,
попробуй через минуту», данные показывает из кэша.

## Технический долг (не блокирует)

- Все 8 весов Unbounded и полный набор шрифтов `@expo/vector-icons` попадают
  в бандл — примерно 7 MB лишнего. Лечится импортом из подпутей.
- Локальная машина на Intel: RN 0.81 распаковывает `React.xcframework` без
  симуляторного слайса, из-за чего `Copy XCFrameworks` падает. Обход —
  скопировать полную версию из `ios/Pods/React-Core-prebuilt/<hash>/`.
  На EAS (Apple Silicon) проблемы нет.
- `src/screens/worker/WorkerProfileScreen.js`: пункт меню «Документы» ведёт
  на экран личных данных, где раздела документов нет.
